# CS-370-Currrent-Emerging-trends-in-CS
Pirate Intelligent Agent Game Project

   As an AI Developer, I am designing a Deep Q-Learning (DQN) reinforcement learning algorithm to train an intelligent NPC pirate agent that must adaptively navigate a complex network of pathways and obstacles to locate treasure before a human player. By leveraging a deep neural network trained through trial-and-error.
   The code that was given to me were:
       1.TreasureMaze.py: This script defined the physics and layout of the game world as a matrix. It handled tracking the pirate's coordinate state, mapping obstacles, calculating valid directional moves (left, right, up, down), and delivering step-by-step rewards or penalties.
       2.GameExperience.py: This class served as the data buffer for experience replay. It was pre-configured to store historical episodes, specifically the state transitions, actions taken, rewards received, and final game statuses.
       3.TreasureHuntGame.ipynb: A baseline Jupyter Notebook containing a skeleton implementation, helper visualization tools, and basic environment setup.
  The code I created was neural network architecture to approximate Q-values from input state vectors and engineered the core qtrain loop to manage the deep reinforcement learning process over multiple episodes. Within this loop, I integrated an epsilon greedy algorithm strategy to handle exploration and exploitation, transitioning the agent from random actions to optimal path exploitation as the network matured. Additionally, I built an experience replay pipeline to sample historical memory batches from GameExperience.py to break data correlation, and implemented telemetry tracking to monitor training loss, calculate cumulative win rates, and determine exactly when the agent achieved pathfinding optimization.
  When solving a complex problem, a computer scientist utilizes algorithmic thinking and computational abstraction by breaking a challenge down into isolated components, identifying matching paradigms like modeling a pathfinding problem as a Markov Decision Process, abstracting the physical environment into a mathematical state action matrix, and iteratively deploying a baseline solution that is systematically optimized through quantitative performance metrics.

Protecting the user requires rigorous testing to eliminate algorithmic bias, securing personal telemetry data against unauthorized exposure, and maintaining transparency to avoid manipulative patterns. Simultaneously, fulfilling organizational responsibilities involves writing clean, resource optimized code to reduce technical debt, safeguarding proprietary framework assets, and providing candid, data driven assessments of a system's true limitations rather than overpromising its capabilities.
